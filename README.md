# AIM_CW-PO
COMP2024 - AIM - Group 15 - NBS ([GitHub](https://github.com/ccrepp/AIM_CW-PO))

Algorithms for Portfolio Optimisation

# Prerequisites
In order to run the files within this repository, the following dependencies are required
- Python 3.8+ with the following libraries
  - numpy
  - pandas
  - matplotlib
  - tabulate
- Jupyter with notebook installed

Alteratively, Google Colab can be used

# Contents
- `PO-GA.ipynb` : Genetic Algorithm for Portfolio Optimisation
- `PO-SA.ipynb` : Simulated Annealing for Portfolio Opimisation
- `PO-MVM.ipynb` : Markowitz Mean-Variance Model for Portfolio Optimisation
- `PO-PSO.ipynb` : Particle Swarm Optimisation for Portfolio Optimisation
- `sp500_10s.csv` : Cleaned sp500.csv file with unstable and stable data

# Running Guide
1. Clone or Download the Repository
2. Set up your environment
3. Prepare input data (csv file)
4. Launch Jupyter Notebook (or Google Colab)
5. Input files (.ipynb and .csv)
6. Check file directory to csv file (ensure correct pathing)
7. Run all cells
8. View output
